## 2. Formal Technical Disclosure

This document serves as the formal academic and competition technical disclosure for the Waypoint Logistics repository.

1. **Design & Problem Formulation**:
   - The logistics network topology, retail outlet constraints, brand profiles (**Fresh**, **Style**, **Tech**), fleet limits, Colombo 16:00 cutoff protocols, and business rules are derived from the official competition case study booklet and team architectural specifications.
   - Initial wireframes and interface structure were designed using Excalidraw design specifications (`reference/design/`).

2. **Tooling & Implementation Workflow**:
   - Software engineering tools, code completion systems, and AI assistant models (including OpenAI Codex and Google Antigravity / Gemini) were utilized during the development lifecycle for codebase scaffolding, routine syntax generation, refactoring, test suite synthesis, and typing verification.
   - All architectural decisions, relational database schemas, state machine definitions, business invariant algorithms (7 Core Feasibility Rules, Fresh dual-order constraints, LIFO reverse sequencing), and cross-role integration contracts were established, verified, and audited by the project engineering team.

3. **Open-Source & Self-Hostability Mandate**:
   - All core capabilities are built using standard open-source technologies (Next.js, NestJS, Fastify, PostgreSQL, Drizzle ORM, PgBouncer, Redis, BullMQ) and run locally or containerized without proprietary SaaS paywalls or paid cloud services.
